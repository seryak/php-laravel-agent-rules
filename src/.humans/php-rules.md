# PHP rules

## PHP

- Всегда использовать фигурные скобки для управляющих конструкций, даже если тело состоит из одной строки.

### Конструкторы
- Использовать promotion свойств конструктора PHP 8 в методе `__construct()`.
    - <code-snippet>public function __construct(public GitHub $github) { }</code-snippet>
- Не допускать пустых методов `__construct()` без параметров.

### Объявления типов
- Всегда указывать явные типы возвращаемых значений для методов и функций.
- Использовать подходящие PHP type hints для параметров методов.

<code-snippet name="Явные типы возвращаемых значений и параметры методов" lang="php">
protected function isAccessible(User $user, ?string $path = null): bool
{
    ...
}
</code-snippet>

## Комментарии
- Отдавать предпочтение PHPDoc-блокам вместо обычных комментариев.
- Никогда не использовать комментарии внутри кода, за исключением случаев, когда реализуется _очень_ сложная логика.
- Не указывать в комментариях тип параметров и возвращаемый тип, если это уже указанов самом методе или функции.

## PHPDoc Blocks
- При необходимости добавлять полезные определения форм массивов (array shape types).

## Enums
- Как правило, ключи в Enum должны быть в TitleCase.  
  Например: `FavoritePerson`, `BestLake`, `Monthly`.
